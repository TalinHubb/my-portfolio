Building Buddy (Progress Tracker)

A web-based tool designed to help players track building upgrades, manage resources, and plan long-term progression efficiently.

Problem

Tracking building upgrades manually is time-consuming and often leads to inefficient resource usage and poor planning.

Solution

Building Buddy provides a structured way to track progress, calculate requirements, and visualize goals, helping users make better decisions.

Key Features

  • Track building levels and upgrades
  • Resource requirement calculations
  • Goal-based progress tracking
  • Simple and intuitive UI

Tech Stack

Challenges
